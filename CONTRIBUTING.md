# 🤝 Contributing to Jigar Tools

Bhai, Jigar Tools ko aur khatarnak banane mein meri madad karo! If you have better logic for Nitro streaming or new God Mode features, follow these steps:

### How to Contribute
1. **Fork the Project**: Apne GitHub par iska ek copy banao.
2. **Create a Feature Branch**: `git checkout -b feature/GodModeFeature`.
3. **Commit your Changes**: `git commit -m 'Add some GodModeFeature'`.
4. **Push to the Branch**: `git push origin feature/GodModeFeature`.
5. **Open a Pull Request**: Main dekhunga aur agar logic solid raha toh merge kar dunga.

### Code Standards
* **No Bloat**: Sirf high-performance logic allowed hai.
* **PS 5.1 Native**: Sarea scripts PowerShell 5.1 compatible hone chahiye.
* **Direct Personality**: No corporate comments; keep it raw.

Together, we'll make the world's most aggressive Android suite. 🚀
