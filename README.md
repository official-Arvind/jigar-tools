## 🔑 Requirements

* **ADB Platform Tools**: [Download Latest Here](https://developer.android.com/tools/releases/platform-tools).
* **USB Debugging**: Must be enabled on the target device.
* **Root (Optional)**: Required for **Full Hybrid** (APK) backups.
* **BusyBox NDK**: Highly recommended for enhanced performance (osm0sis build).

### ⚠️ Essential Magisk Settings (For Rooted Users):
If you have root, go to **Magisk Manager > Superuser > Shell** and set **Mount Namespace Mode** to **Global Namespace**. This ensures the backup stream can see your entire filesystem.

## 📂 Restore Guide

1. **Extract**: Use **7-Zip** to extract your `.tar` backup. (Standard Windows extractor is garbage for .tar).
2. **Target**: Connect your phone and run **Jigar Tools > Restore**.
3. **Confirm**: The script will install your apps first, then push your files back home.
