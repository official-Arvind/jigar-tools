## 🧪 What's New in Beta 2.0.1

This beta release introduces major quality-of-life improvements to the Master Control Center, setting the stage for future seamless updates.

### ✨ Major Features
- **In-App Auto-Updater**: The main `Jigar_Tools_Setup.bat` now features an integrated GitHub release fetcher. You can effortlessly switch between the **STABLE** and **BETA** channels and download the exact version you want directly inside the terminal.
- **Universal App Backup Helper**: Integrated directly into the `[3] DEVICE STATUS` menu. The tool now dynamically detects your connected smartphone brand (Xiaomi, Oppo, OnePlus, Vivo, Huawei, Samsung, etc.) and provides brand-specific on-screen instructions on how to trigger a system-level local app backup *before* you run the Titan Backup Engine. 

### 🐛 Bug Fixes
- **Batch Syntax Parsing**: Fixed multiple crashing bugs in the Auto-Updater where the Windows Batch parser choked on unquoted pipe (`|`) and redirection characters.
- **Elevation Prompt Consistency**: Restored the UAC God Mode elevation check to ensure the updater and scripts have sufficient permissions to run system commands.

## 📥 Installation & Setup

> [!WARNING]
> This is a **Beta** release. It may contain bugs or experimental features.

1. **Download** the `Jigar_Tools_Beta_V2.0.1.zip` archive attached below.
2. **Extract** the package contents to a directory on your PC.
3. **Right-click** `Jigar_Tools_Setup.bat` and select **Run as Administrator** to initialize the environment and run the launcher.
