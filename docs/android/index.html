Under the hood

From install to done.

Four steps. That's all it takes to back up every file on your Android device.

01

Install & Grant Root

Install the APK and grant Root permissions (via Magisk, KernelSU, or APatch) on first launch.

02

Phone gets scanned

The app uses native root commands to instantly index your installed packages and internal app data. — file paths and sizes. 100,000 files indexed in under 10 seconds depending on your device speed.

03

You choose what to sync

The Material UI lists all your apps, media, and call history. Select the packages you want to protect. with lazy-loaded children. Check what you want, uncheck what you don't. Or just hit Skip to back up everything.

04

Titan Engine fires up

The native C++ backend fires up. Using Zstandard compression, it rapidly packages your data and streams it directly to your NAS, SMB server, or local storage without using PC cables. A live progress bar shows throughput in MB/s, total progress, and per-file status. When it's done, the drive unmounts, temp files clean themselves up, and you get a log.

FAQ

Real questions, straight answers.

Do I need to be rooted?

Root is required if you want to backup internal app data (like game saves or logged-in accounts) and Wi-Fi passwords. If you aren't rooted, you can still backup APK files, Call History, and basic storage.

Where are my backups stored?

By default, backups are safely compressed into archives within your internal storage. However, you can instantly configure Jigar Backup to stream these archives directly to your personal Cloud, WebDAV, or SMB network server to save local storage.

How fast is it actually?

That's limited by your phone's internal memory speed and your phone's storage speed, not by the tool. With Zstandard compression running via the native C++ engine, modern phones can compress and backup data at hundreds of megabytes per second.. Budget phones with USB 2.0 controllers cap out around 25–35 MB/s. It operates directly on the device, eliminating the bottleneck of a USB cable.

Can I automate it? Run it without prompts?

Yes. Yes. Jigar Backup allows you to configure scheduled backups. You can select specific apps and let it run automatically in the background without any manual intervention. It'll skip the folder picker (uses the saved location from settings.json) and bypass the GUI filter menu, making it suitable for scheduled tasks or scripted automation.

Does it support Multi-User or Work Profiles?

Yes! Jigar Backup fully supports cross-profile operations. It can detect and backup applications installed in your Secure Folder, Dual Spaces, or Android Work Profiles effortlessly.

Is this actually free? What's the catch?

Fully free, MIT licensed, open source on GitHub. No telemetry, no accounts, no cloud syncing your data anywhere. It's an Android app compiled from open source. No servers, no tracking, no hidden fees.
